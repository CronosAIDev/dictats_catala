# Secció: Mobile

## Descripció

Vista mòbil de l'app (`/mobile`), pensada per usar-se al mòbil mentre es fa el dictat en
paper. Mateix flux funcional que la secció Dictat, adaptat a pantalla petita.

## Funcionalitats principals

- Mateixes funcionalitats que `dictat`, layout adaptat a mòbil
- Pensada per al cas d'ús "escoltar al mòbil, escriure en paper"

## Components clau

- **Vista HTML**: `public/mobile.html`
- **Rutes API**: comparteix `src/routes/dictats.js` amb la vista desktop
